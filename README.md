# IP 操盘工具箱

公开网站：https://ouweikang000910.github.io/ip-operator-toolbox/

五个创作入口：每日 50 条选题雷达、商单要求拆解器、长视频切片助手、气口剪辑、视频镜头库。保留星空背景与手机布局，无需登录。

## 数据更新

GitHub Actions 约每半小时读取百度、今日头条、微博的公开榜单，合并同标题、按名次加权排序并自动分类。各来源失败时显示实际状态；同日可回退到标注的缓存，昨日内容不会伪装成今天。可用候选不足 50 条时显示实际数量。不同写法的同事件可能未合并；仅代表接入来源，不保证全网绝对排名。

网页刷新读取最近一次发布的榜单，不触发服务器即时抓取。更新时间以页面为准。GitHub 定时任务可能延迟；公共仓库连续 60 天无活动时，GitHub 可能停用定时任务，可到 Actions 重新启用。维护者可以在 Actions 中手动运行发布工作流。

商单原文、清单和历史仅在访客自己的浏览器处理及保存；其他三个工具在原站独立运行。这个仓库不包含本机 IP 档案、个人素材、环境配置或旧的数据管理接口。

## 本地构建与发布

需要 Node.js 22，无需安装第三方依赖。

```sh
npm test
npm run build
npm run radar:update
```

生成目录为 dist，使用静态服务器预览。GitHub Settings → Pages 的 Source 选 GitHub Actions。推送 main 或手动运行工作流后发布。只发布显式允许的网页文件及热榜 JSON，源码和配置不直接进入网页目录。

原本的本机服务在原项目内继续保留；本仓库是独立的 GitHub Pages 发布版本。
