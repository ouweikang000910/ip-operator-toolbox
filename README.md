# IP 操盘工具箱

公开网站：https://ouweikang000910.github.io/ip-operator-toolbox/

七个创作入口：每日 50 条选题雷达、商单要求拆解器、长视频切片助手、气口剪辑、净帧去水印、AI 视频复盘官、视频镜头库。黑底橙红像素花朵、衬线大标题与简洁工具目录，支持暂停背景动效与手机布局，无需登录。

## 选题雷达背景

黑底搭配底部橙红与冷蓝柔光，三层流光以 32–46 秒周期缓慢漂移和明暗变化。只有背景移动，文字与卡片保持稳定；右上角背景按钮可暂停、继续，系统开启减少动态效果时保持静止。样式仅应用于选题雷达。

## 按方向搜索热门选题

进入每日选题雷达，输入任意方向后按 Enter 或点击「联网找选题」。搜索会把提交的关键词发送到联网服务，实时查询新浪新闻搜索等公开来源，独立于每日 50 条及历史索引。

支持近 7 天、今天、不限时间。新闻结果展示来源发布时间、分类、原文链接与自动创作切入；同标题合并，按搜索源相关性顺序整理。没有取得有效新闻时会继续查询 Bing 网页 RSS，并明确标注「发布时间待核验」，不把网页时间当新闻发布时间。来源全部失败时显示错误与重试，不回退成本地匹配。

这些结果是相关选题线索，未获取阅读、点赞等数据，不保证全网热度排名。相同查询可复用 2 分钟内的服务缓存；复制会携带来源链接与日期。联网服务为 https://ip-radar-web-search.wuliaowei2077.chatgpt.site/api/search ，无访客账户、密钥或私人工作区数据。

## 数据更新

GitHub Actions 约每半小时读取百度、今日头条、微博的公开榜单，合并同标题、按名次加权排序并自动分类。各来源失败时显示实际状态；同日可回退到标注的缓存，昨日内容不会伪装成今天。可用候选不足 50 条时显示实际数量。不同写法的同事件可能未合并；仅代表接入来源，不保证全网绝对排名。

每次抓取的新标题持续写入搜索历史，通过 Actions 缓存保留；缓存缺失时会尝试从已发布的搜索索引恢复。公开索引只包含公开热点标题、分类、平台名次与链接，没有访客输入或本机私人资料。

网页刷新读取最近一次发布的榜单，不触发服务器即时抓取。更新时间以页面为准。GitHub 定时任务可能延迟；公共仓库连续 60 天无活动时，GitHub 可能停用定时任务，可到 Actions 重新启用。维护者可以在 Actions 中手动运行发布工作流。

商单原文、清单和历史仅在访客自己的浏览器处理及保存；视频复盘记录也仅保存在当前浏览器，其他工具在原站独立运行。这个仓库不包含本机 IP 档案、个人素材、环境配置或旧的数据管理接口。

## 本地构建与发布

需要 Node.js 22。主工具箱无需第三方依赖；构建视频复盘官时会按锁文件安装独立的前端和 OCR 依赖，并运行其测试与构建。

```sh
npm test
npm run build
npm run radar:update
```

生成目录为 dist，使用静态服务器预览。GitHub Settings → Pages 的 Source 选 GitHub Actions。推送 main 或手动运行工作流后发布。只发布显式允许的网页文件及热榜 JSON，源码和配置不直接进入网页目录。

原本的本机服务在原项目内继续保留；本仓库是独立的 GitHub Pages 发布版本。

## AI 视频复盘官

公开入口：https://ouweikang000910.github.io/ip-operator-toolbox/video-review/

支持 MP4/MOV 浏览器提帧、中英文截图 OCR、运营指标与真实证据报告、历史对比和报告导出。保留霓虹万圣节主题，无需账户登录。素材与历史使用 IndexedDB 保存在访客自己的浏览器中；清除网站数据可能丢失记录，重要报告请导出。不同设备不自动同步。

可选 AI 分析使用访客自己的兼容视觉 API 服务；API Key 只保存在页面会话内存中，刷新即清空，网站不提供共享的付费额度。仅点击复盘时向访客配置的服务发送压缩帧和资料，服务须支持 CORS；未配置时不伪造内容判断。当前不自动转写音频，可粘贴逐字稿或 SRT。

源码位于 `video-review-app/`。构建时通过 npm 锁文件取得固定版本 Tesseract 引擎及中英文语言数据，复制到站点同源 OCR 目录。访客无需从第三方 CDN 加载识别代码，视频与测试数据库不会进入仓库或发布目录。
