# Briefly 2 · 商单要求细分

- 先拆出可独立检查的要求，再逐项分类。支持常见逗号、顿号和连接词；引号内文案、描述性列表和金额千位分隔符保留。
- 视频交付数量与时长分别检查；防漏测试、品牌露出、禁止事项和交付排期分别归类。每项保留原文片段和字符位置。
- 清单进度改为人工自查；品牌审核状态单独记录，勾选不会自动改变审核状态。
- 编辑检查项可填写检查方法、检查记录 / 证据位置和执行备注；Markdown、JSON 和打印保留这些记录。
- 根据原文的缺口生成待确认问题。相对日期不自动推算；不补写测试时长、动作等品牌未指定的条件。

## 旧项目与备份

本地存储键保持不变；原有项目不自动重写。打开旧项目可点击“升级细分旧清单”。升级创建一个新版本，旧版本仍在历史记录中。

同名项目重新拆解会匹配未变化的检查项，保留自查、备注和证据。合并项细分后只复制旧备注，检查状态重置；旧证据单独标为需复核。原文变更后审核状态重置为未提交。历史仍最多保留30个版本，重要项目请导出备份。

支持导入旧版 version 1 JSON；新版导出为 version 2。品牌确认结果仅在问题及依据不变时继承。
