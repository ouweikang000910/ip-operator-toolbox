# AI 视频复盘官 · GitHub Pages 公开版

公开网址：https://ouweikang000910.github.io/ip-operator-toolbox/video-review/

复用视频复盘官的霓虹主题和复盘界面，适配 GitHub Pages 的静态环境。无需登录，无服务端数据库，每位访客的视频、截图识别和历史记录均由其自己的浏览器处理。

## 使用

1. 导入浏览器能解码的 MP4/MOV，最大 200 MB、20 分钟。推荐 H.264 + AAC。
2. 填写标题、账号、统计窗口与已知指标；截图 OCR 结果必须人工核对。可粘贴逐字稿或 SRT。
3. 生成基于真实关键帧和运营数据的报告，查看历史对比与账号洞察，可复制或导出报告。
4. 需要 AI 内容分析时，在“设置与 AI 服务”填写自己的 HTTPS 兼容视觉 API 地址、模型及 Key。服务必须支持 CORS、图像输入及 JSON 输出。

未配置 AI 时不会生成内容主观评分或伪造文案。AI Key 仅保存在当前页面的内存中，刷新即清空；不使用作者账户额度。仅点击复盘才向访客选择的服务发送标题、字幕、指标和最多 8 张压缩帧。浏览器不会自动转录音频，未提供字幕时不判断口播。

IndexedDB 记录不会自动跨设备同步。清除网站数据、使用无痕模式或浏览器自动回收空间可能丢失记录；重要报告请及时导出。每个浏览器最多 1000 条视频，容量取决于浏览器配额。更新资料后旧报告失效；删除时同时删除视频与关键帧。分析时保持页面打开，中断后可重试。

## 开发

Node.js >= 22。

```sh
npm ci --ignore-scripts
npm test
npm run build
npm run dev
```

`npm run build` 从锁文件固定的 npm 包复制 Tesseract 引擎、中英文数据和许可证到 public/ocr，再构建 dist。识别资源与网页同源提供，访客素材不会传给 CDN。

在 IP 工具箱仓库中，本项目位于 `video-review-app/`。主仓库的 `scripts/build-video-review.mjs` 安装依赖、运行测试并构建，再仅将 dist 复制到工具箱发布目录的 video-review/。现有 GitHub Pages 工作流会在推送 main 后自动发布。此源代码不包含私人 Sites 站点 ID、服务器环境、视频、历史记录、测试截图或密钥。

## 验证

19 项规则和 IndexedDB 测试覆盖真实零值、缺失值、历史基准、证据校验、事务回滚、修改失效报告、跨标签并发与关联媒体删除。浏览器实测 6 秒视频提取 8 帧、OCR 6 个字段核对、保存报告与刷新后持久化。未配置真实 AI 服务，未进行付费模型联网验收。
